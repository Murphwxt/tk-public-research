# TK 公开资料研究与阅读索引

非于旸 / Tombkeeper 本人官方项目。本项目整理其公开阅读与观点材料，并区分本人表达、第三方保存和研究者归纳。

研究截止：2026-09-20。370 项资料、20 项优先阅读建议、25 条方法论归纳、55 条短摘录。
做这个项目的目的是，想保存下来，TK所推荐过的书籍，作品等各方面的内容。避免账号消失带来的记忆消逝。
## 阅读

- `index.html`：独立网页，带搜索、筛选和目录跳转；下载后也可以直接用浏览器打开。
- `report.md`：完整七部分报告。
- `evidence.json`：资料目录与证据索引。

## GitHub Pages 发布

1. 创建公开仓库，例如 `tk-public-research`。
2. 将本目录内的文件放在仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库 **Settings → Pages → Build and deployment**。
4. Source 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`，保存。
5. 等待发布完成，Pages 设置页会显示网站链接。

GitHub 官方文档：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 证据边界与纠错

- 本项目不是全部历史微博的完整存档，不能称为绝对全集。
- “提及”“认可”“推荐”“批评”分别标注；阅读排序和方法论归纳不是 TK 本人发布的榜单或理论。
- 第三方整理站不等于本人网站；近期账号关联和部分失效原链接仍待核验。
- 原始链接、保存链接、日期与可信度尽量逐项保留。
- 如需纠错，请在仓库 Issues 提供条目编号、问题说明和可验证出处；维护者可据此更新。
- 引文、作品名称及第三方材料的权利属于各自权利人；本项目未对这些材料授予额外许可。

## 更新

直接更新仓库中的网页及资料文件，GitHub Pages 会按所选发布分支重新部署。请同时维护正文的研究截止日期和证据说明。
